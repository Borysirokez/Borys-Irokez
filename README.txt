III RP — STRONA INTERNETOWA
===========================

ZAWARTOŚĆ
- index.html  — treść strony
- style.css   — wygląd i responsywność
- script.js   — menu mobilne i aktualny rok

JAK URUCHOMIĆ LOKALNIE
1. Rozpakuj plik ZIP.
2. Otwórz folder iii_rp_strona.
3. Kliknij dwukrotnie index.html. Strona powinna otworzyć się w przeglądarce.
   Do samego podglądu nie trzeba instalować żadnych programów.

JAK ZMIENIĆ LINK DO DISCORDA
1. Otwórz index.html w edytorze tekstu.
2. Znajdź https://discord.com/ (występuje przy przycisku „Przejdź na Discord”).
3. Zastąp ten adres własnym linkiem zaproszenia, np. https://discord.gg/TWOJ_KOD.
4. Zapisz plik.

JAK EDYTOWAĆ TREŚĆ
- Teksty i nagłówki zmieniaj w index.html.
- Kolory, odstępy i układ zmieniaj w style.css.
- Zachowaj wszystkie trzy pliki w tym samym folderze.

JAK OPUBLIKOWAĆ W INTERNECIE
Najprościej użyć hostingu statycznego, np. GitHub Pages lub Netlify:
- Utwórz konto w wybranym serwisie.
- Prześlij pliki index.html, style.css i script.js (lub cały folder zgodnie
  z instrukcjami hostingu).
- Włącz publikację strony i skopiuj otrzymany publiczny adres.
Nazwy przycisków i dokładne kroki zależą od aktualnego interfejsu hostingu.

UWAGA
To projekt społecznościowy, nie oficjalna strona instytucji państwowych.
Sekcje aktualności są przykładowe. Przed publikacją dodaj własne treści,
sprawdź wszystkie linki i opublikuj tylko informacje, do których masz prawa.
Czcionki Google Fonts mogą wymagać połączenia z internetem; strona ma też
zapasowe czcionki systemowe.
